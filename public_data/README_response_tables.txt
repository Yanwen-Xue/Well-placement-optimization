Public derived response tables

Supplementary_Data_679_Layouts_Three_Responses.csv contains one row for each of the 679
completed layout simulations. The first 20 coordinate columns give the five injector and five
producer well locations as zero-based model-grid I/J indices. F1 is the maximum reservoir-average
pressure increase over the 80-year simulation, reported as percent relative to the initial
pressure. The pressure peak time is reported in years from the start of simulation. F2 is the
horizontal projection of mobile CO2 at the end of the 30-year injection period, using the
gas-saturation threshold of 0.10, in km2. F3 is the dimensionless normalized pressure-buildup
heterogeneity at 30 years.

Supplementary_Data_Pareto_240_Layouts_Three_Responses.csv contains the 240 non-dominated
layouts identified on the surrogate response surface. It reports their well locations using the
same zero-based model-grid I/J convention, the same three response quantities, and the
surrogate evaluation label.

The files contain derived layout and response data only. They do not disclose the static
geological model, CMG input files, SIP files, full-physics binaries, or restricted site data.
